# HRI Task 詳細技術仕様

このドキュメントでは、HRIタスクを構成する各Pythonファイルの内部ロジックや、パラメータの調整方法といった技術的な詳細をまとめています。
タスクの全体の流れ（ステートマシンの動き）については、メインの `README.md` をご参照ください。

---

## 1. 設定・キャリブレーション (`g1_config.py`)

ロボットの物理的な寸法、カメラの位置パラメータ、関節の角度制限、移動のしきい値などを一元管理する設定ファイルです。

*   **腕の届く距離がおかしい場合**: `RobotGeometry` の `L_UPPER` (肩〜肘) や `L_LOWER` (肘〜手先) などの数値を実測値に合わせて変更します。
*   **カメラの位置や角度が実機とズレている場合**: `CameraParams` の `CAM_FROM_NECK_X` などを修正します。実機調整時は**基本的にこのファイルだけ**を書き換えることで全体に反映されるように設計されています。

## 2. 関節・姿勢の直接制御 (`direct_joint_control.py`)

MoveIt 等の高度なプランナーを使わず、ロボットの関節（腕や腰）の目標角度を直接パブリッシュし続けるコントローラーです。

*   **10Hzのバックグラウンドパブリッシュ**: 音声合成など長時間の動作中にも腕が下がる（力が抜ける）のを防ぎ、姿勢を保持します。（過去に50Hzでパブリッシュした際にナビゲーションモジュールとの通信干渉が発生したため、現在は10Hzに落として両立させています）
*   **ポーズの変更**: ファイル上部にある `HOME_POSE` や `ARM_POSE_EXTEND_RIGHT` などの辞書に入っている各関節の角度（ラジアン）を調整します。
*   **動作スピードの変更**: `_publish_loop` 内の `max_step` の数値を調整します（数値を小さくするとゆっくり動き、大きくすると速く動きます）。

## 3. 逆運動学の計算 (`bag_grasp_ik.py`)

カメラで見つけた物体（カバンや椅子など）の座標から、「腕の肩と肘をそれぞれ何度曲げれば届くか」を数学的に計算するファイルです。

*   **掴む・指差すときの腕の姿勢を変えたい場合**: この中の `calculate_bag_grasp_joints` や `solve_2link_ik` の数式・制限値を調整します。純粋な数学的計算のため、通常はあまり触る必要はありません。

## 4. EKFによるトラッキング (`yolo_track.py`)

YOLOで検出した人の方向へロボットのベース（足回り）を移動させるためのトラッカーです。

*   **EKF（拡張カルマンフィルタ）**: 人の動きを予測しつつ、同時に LiDAR の点群情報を使って障害物を避ける（カニ歩き等）制御を行います。
*   **人との維持距離**: ファイル上部の `FOLLOW_DISTANCE = 0.8` (m) を変更します。
*   **追従スピード**: `LINEAR_MAX` や `ANGULAR_MAX` の数値を調整します。
*   **障害物回避**: LiDARに関する設定値（`LIDAR_Z_MIN`, `LIDAR_X_MAX` など）を変更します。

## 5. YOLOコンテナ側の処理 (`yolo_human/`)

メインの ROS ノードとは別の Docker コンテナで動き、カメラ画像を処理するモジュール群です。

*   **`yolo_human_node.py`**:
    *   YOLO を用いてリアルタイムにカメラ画像から人物と物体を検出・トラッキングします。
    *   検出対象を増やす場合は、デフォルトの `target_classes` に "chair" や "bag" などを追加します。
*   **`clothing_analyzer.py`**:
    *   OpenAI API が使えない環境（オフライン）でのフォールバックとして、服の色（KMeans）や柄（CLIP）を判定します。
    *   分類ルールは `_COLOR_RULES` の HSV のしきい値や、 `PATTERN_LABELS_EN` などを変更します。
*   **`extract_person_features.py`**:
    *   OpenAI Vision API (GPT-4o 等) を呼び出して、画像から詳細な人物の特徴（服の種類や色、眼鏡の有無など）を自然言語で抽出します。
    *   抽出の指示を変えたい場合は `prompt` に書かれている文字列を書き換えます。
