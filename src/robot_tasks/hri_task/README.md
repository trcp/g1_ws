# HRI Task パッケージ概要

このパッケージは、G1ロボットにおける HRI (Human-Robot Interaction) タスクを実行するための ROS2 / Python パッケージです。
ゲストの出迎え、特徴の抽出、追従、空席への案内、ゲスト同士の相互紹介など、一連のタスクをSMACH（ステートマシン）で自動制御します。

⚠️ **注意**: 逆運動学(IK)やトラッキングの数式、各スクリプトの詳しい技術仕様については、別ファイルの [**`DETAILS.md`**](DETAILS.md) をご参照ください。

---

## 🚀 起動方法と開発のコツ

*   **メイン制御（WezTerm経由）**:
    WezTerm上で設定された `HriMain` や `YoloHuman` パネルから自動起動できます。
*   **YOLO側の開発時のコツ**:
    `yolo_human` 内の Python ファイル（`yolo_human_node.py` など）は `docker-compose.yml` で直接マウントされているため、**ホスト側のコードを保存してコンテナを再起動（compose down & up）するだけでそのまま反映**されます。Docker のビルドをやり直す必要はありません。

---

## 🔄 全体のステート遷移（タスクの流れ）

タスクは `main.py` のSMACHによって管理されており、大きく「1周目（ゲスト1の対応）」「2周目（ゲスト2の対応）」の2つのフェーズに分かれています。

### 1周目 (ゲスト1) のフロー
1. **ドアベル待機** ➡️ **玄関へ移動**
2. **人物の発見と追従**
3. **挨拶と情報（名前・飲み物・特徴）の取得**
4. **リビングへの案内**
5. **空席を探して指差す**

### 2周目 (ゲスト2) のフロー
1. **玄関へ戻る** ➡️ **人物の発見と追従**
2. **挨拶と情報（名前・飲み物・特徴）の取得**
3. **ゲスト1（ホスト）の特徴を伝える**
4. **(オプション) カバンの受け取り**
5. **リビングへ案内し、ゲスト同士を紹介し合う**

## 📝 各ステート（状態）の詳細と機能

ここでは、タスク中にロボットが「どこで何をしているか」を上から順に解説します。

### 🚪 玄関への移動と人物発見
*   **`WAIT_DOOR`**
    *   **機能**: ドアベルが鳴るのを待機するステートです。（※現在はスキップ設定になっています）
*   **`MOVE_TO_ENTRANCE`**
    *   **機能**: ナビゲーションシステムを使って玄関（設定された座標）へ自動で移動します。移動中は姿勢をキープします。
*   **`TRACK_PERSON`** (定義: `yolo_states.py`)
    *   **機能**: YOLOを使って人物を探し、ロボットの正面に人が来るように自動で腰（Waist）を回転させて追従します。

### 🗣️ 挨拶と特徴の抽出
*   **`GREET_GUEST`** (定義: `main.py` 内のサブステート)
    *   **機能**: ロボットが「名前と好きな飲み物を教えてください」と問いかけます。
    *   **STT（音声認識）**: 返答の中からキーワードを抽出して記憶します。
    *   **特徴抽出**: バックグラウンドでOpenAI Vision APIを使用し、ゲストの服の色、眼鏡の有無などの視覚的特徴を自動抽出して記録します。

### 🛋️ リビングへの案内と着席
*   **`MOVE_TO_LIVING`**
    *   **機能**: ゲストに「ついてきてください」と伝え、リビング（椅子の前）の座標へ移動します。
*   **`FIND_EMPTY_SEAT`** (定義: `yolo_states.py`)
    *   **機能**: YOLOで「人」と「椅子」を検出し、重なり具合（IoU）を計算して「誰も座っていない椅子」が左から何番目にあるかを判定します。
*   **`POINT_SEAT`**
    *   **機能**: 計算された空席の方向に向けて、逆運動学（IK）を使って腕を動かし、指差し動作を行いながら着席を促します。

### 🤝 ゲスト2特有のアクション
*   **`DESCRIBE_GUEST_1`**
    *   **機能**: 玄関でゲスト2を出迎えた際、「ゲスト1は赤い服を着ています」など、事前に記憶したゲスト1の特徴を音声で伝えます。
*   **`BAG_GRASP_INTERACTION`** (定義: `yolo_states.py`)
    *   **機能**: ロボットが両腕を前に伸ばし、ゲストからカバンを受け取る（または置く）インタラクションを行います。
*   **`INTRODUCE_GUESTS`**
    *   **機能**: リビングに到着後、ゲスト1の方を向いてゲスト2を紹介し、次にゲスト2の方を向いてゲスト1を紹介する（顔を向けながら腕で指し示す）という高度な相互紹介アクションを行います。

## 🛠️ よくある設定の変更方法（クイックガイド）

基本的な挙動を変えたい場合は、主に `main.py` を修正します。

*   **話す言葉（セリフ）を変えたい**
    *   `main.py` の各ステート生成部分にある `message="..."` や、コールバック内の `SAY("...")` の文字列を変更してください。
*   **タスクの順番を入れ替えたい**
    *   `main.py` の `smach.StateMachine.add(...)` の定義順序や、`transitions={'success': '次のステート'}` の部分を書き換えることで、自由にタスクを組み替えることができます。
*   **移動する場所（座標）を変えたい**
    *   `main.py` の上部にある `LOCATIONS = {'entrance': [-3.1, 0.82, 3.16], ...}` のX, Y, Yaw(向き)の数値を変更してください。
*   **聞き取る名前・飲み物のリストを増やしたい**
    *   `main.py` 上部の `TARGET_DICT` のリストに新しい単語を追加してください。
